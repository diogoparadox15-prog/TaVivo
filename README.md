# TaVivo
TaVivo: Assistente de emergência e sobrevivência 100% offline para dispositivos de até 8 GB RAM. Combina IA local multimodal (LFM3-Omni-2B via llama.cpp) com biblioteca médica/sobrevivência em PT-BR (SQLite FTS5), geolocalização de 5.571 municípios e rios do Brasil, e travas antialucinação. Construído por Capitain Of Cruzades.
