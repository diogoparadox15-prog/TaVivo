# Antenas Improvisadas e LoRa / Meshtastic

1. ANTENA DIPOLO DE MEIA ONDA IMPROVISADA:
   - Fórmula do comprimento total em metros: L = 142,5 / f (onde f é a frequência em MHz). Cada braço do dipolo mede L / 2 = 71,25 / f.
   - Exemplo para VHF 146 MHz: L ≈ 142,5 / 146 = 0,976 m (dois braços de ~48,8 cm cada).
   - Exemplo para PX 27 MHz: L ≈ 142,5 / 27 = 5,27 m (dois braços de ~2,64 m cada).

2. LORA / MESHTASTIC OFF-GRID (SEM INTERNET NEM TORRE DE CELULAR):
   - Rádios LoRa (915 MHz no Brasil) criam rede mesh de texto e GPS entre aparelhos.
   - Regra de ouro — Linha de Visada e Zona de Fresnel: obstáculos físicos (morros, prédios de concreto, mata densa) bloqueiam o sinal de 915 MHz. Um aparelho colocado em ponto elevado (telhado, morro, torre) operando como repetidor amplia o alcance de poucas centenas de metros para dezenas de quilômetros.
